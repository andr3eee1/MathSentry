# MathSentry High-Converting Landing Page

A production-ready, pixel-perfect SaaS landing page for **MathSentry** — an AI-powered mathematical proof verification engine that pinpoints logical gaps in handwritten mathematical proofs without giving away solutions.

## Tech Stack
- **Framework**: Vite + React 18 + TypeScript
- **Styling**: Tailwind CSS with custom OKLCH/HSL tokens & custom animations
- **Typography**:
  - UI: `Inter`
  - Mathematics & Editorial: `Newsreader` / `Crimson Pro`
  - Code & AST: `JetBrains Mono`
- **Icons**: Lucide React

## Running Locally

```bash
cd landing
npm install
npm run dev
```

The landing page will be accessible at `http://localhost:5173`.

## Production Build

```bash
npm run build
npm run preview
```
